# Local data directory

Course-provided datasets and checkerboard captures are intentionally excluded
from the personal repository. Place the extracted F1/10 dataset at:

```text
data/f110_dataset_20220209/f110_dataset_20220209/
```

That directory must contain `0.jpg` through `1791.jpg` and `labels.npy`.
Place the 14 checkerboard images in `data/calibration/` before rerunning camera
calibration. These files remain local and are not uploaded by this project.
